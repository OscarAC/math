    \problem[6] Congruence modulo 5 is a relation on the set $A = \mathbb{Z}$. In this relation $xRy$ means $x \equiv y \pmod{5}$. Write out the set $R$ in set-builder notation.

    \answer $R = \set{(x,y) \in \mathbb{Z} \times \mathbb{Z} : 5 \mid (x-y)}$.

    \problem Let $A = \set{1,2,3,4,5,6}$. Observe that $\emptyset \subseteq A \times A$, so $R = \emptyset$ is a relation on $A$. Draw a diagram for this relation.

    \answer Since $R = \emptyset$, no pair $(x,y)$ belongs to $R$, so the diagram has a node for each element of $A$ and no arrows at all.

    \problem Consider the subset $R = (\mathbb{R} \times \mathbb{R}) - \set{(x,x) : x \in \mathbb{R}} \subseteq \mathbb{R} \times \mathbb{R}$. What familiar relation on $\mathbb{R}$ is this? Explain.

    \answer The relation is \textit{not equal ($\neq$)}. The set contains every pair $(x,y)$ of real numbers. Removing the pair $(x,x)$ leaves exactly the pairs where x and y differ.

\subsection{Properties of Relations}

\begin{problems}
    \problem Consider the relation $R = \set{(a,b),(a,c),(c,c),(b,b),(c,b),(b,c)}$ on the set $A = \set{a,b,c}$. Is $R$ reflexive? Symmetric? Transitive? If a property does not hold, say why.

    \answer This is not reflexive because $(a,a) \notin R$.\\ 
    This is not symmetric because $(a,b) \in R$ but $(b,a) \notin R$.\\ 
    This is transitive: checking every chain $xRy$, $yRz$ of pairs in $R$ confirms that $(x,z) \in R$ in each case.

    \problem Let $A = \set{a,b,c,d}$. Suppose $R$ is the relation
        \[
            \begin{aligned}
                R = \{ & (a,a),(b,b),(c,c),(d,d),(a,b),(b,a),(a,c),(c,a),\\
                       & (a,d),(d,a),(b,c),(c,b),(b,d),(d,b),(c,d),(d,c) \}.
            \end{aligned}
        \]
        Is $R$ reflexive? Symmetric? Transitive? If a property does not hold, say why.

    \answer This is reflexive because $xRx$ holds for every $x \in A$.\\ 
    This is symmetric because $xRy$ and $yRx$ both hold for every $x,y \in A$.\\ 
    This is transitive because $xRz$ holds for every $x,z \in A$, regardless of $y$.

    \problem Consider the relation $R = \set{(x,x) : x \in \mathbb{Z}}$ on $\mathbb{Z}$. Is $R$ reflexive? Symmetric? Transitive? If a property does not hold, say why. What familiar relation is this?

    \answer Here $xRy$ if and only if $x = y$, so $R$ is the equality relation $=$ on $\mathbb{Z}$.\\ 
    This is reflexive because $x = x$ for every $x \in \mathbb{Z}$.\\ 
    This is symmetric because $x = y$ implies $y = x$.\\ 
    This is transitive because $x = y$ and $y = z$ imply $x = z$.

    \problem Define a relation on $\mathbb{Z}$ as $xRy$ if $\abs{x-y} < 1$. Is $R$ reflexive? Symmetric? Transitive? If a property does not hold, say why. What familiar relation is this?

    \answer Since $x-y$ is an integer and the only integer with absolute value less than 1 is 0, we have $xRy$ if and only if $x-y = 0$, that is, $x = y$. So $R$ is the equality relation $=$ on $\mathbb{Z}$.\\ 
    This is reflexive because $x = x$ for every $x \in \mathbb{Z}$.\\ 
    This is symmetric because $x = y$ implies $y = x$.\\ 
    This is transitive because $x = y$ and $y = z$ imply $x = z$.

    \problem Suppose $A \neq \emptyset$. Since $\emptyset \subseteq A \times A$, the set $R = \emptyset$ is a relation on $A$. Is $R$ reflexive? Symmetric? Transitive? If a property does not hold, say why.

    \answer This is not reflexive. Pick any $x \in A$, then $(x,x) \notin R$ because $R = \emptyset$.\\ 
    This is symmetric because it is impossible to find a $(x,y) \in R$ for which $(y,x) \notin R$.\\ 
    This is transitive because $xRy \land yRz$ implies $xRz$ for every $x,y,z \in A$.

    \problem Prove that the relation $|$ (divides) on the set $\mathbb{Z}$ is reflexive and transitive. (Use Example 11.8 as a guide if you are unsure of how to proceed.)

    \begin{proof}
        First we will show that $\mid$ (divides) is reflexive. Take any integer $x \in \mathbb{Z}$. Since $x = x \cdot 1$ and $1 \in \mathbb{Z}$, the definition of divisibility gives $x \mid x$. Thus $\mid$ is reflexive.

        Next, we will show that $\mid$ is transitive. For this, we must show that if $x \mid y$ and $y \mid z$ then $x \mid z$.
        Suppose $x \mid y$ and $y \mid z$. This means $y = xm$ and $z = yn$ for some integers $m$ and $n$. Substituting $xm$ for $y$ we get $z = (xm)n = x(mn)$, and by definition of divisibility, we see $x \mid z$.

        The past two paragraphs show that $\mid$ is reflexive and transitive on $\mathbb{Z}$.
    \end{proof}

    \problem Suppose $R$ is a symmetric and transitive relation on a set $A$, and there is an element $a \in A$ for which $aRx$ for every $x \in A$. Prove that $R$ is reflexive.

    \answer
    \begin{proof}
        Let $R$ be a transitive and symmetric relation in $A$. And assume there is an element $a \in A$ such that $aRx$ for every $x \in A$. We want to prove that $xRx$ for every $x \in A$.

        Take any $x \in A$.
        Since $aRx$ for every $x \in A$, we have $aRx$.
        Because $R$ is symmetric, we have $xRa$.
        So we have both $xRa$ and $aRx$.
        Because $R$ is transitive, $xRa$ and $aRx$ imply $xRx$.
        Therefore, $R$ is transitive, symmetric, and reflexive.
    \end{proof}

    \problem Define a relation $R$ on $\mathbb{Z}$ by declaring that $xRy$ if and only if $x^2 \equiv y^2 \pmod{4}$. Prove that $R$ is reflexive, symmetric and transitive.

    \answer 
    \begin{proof}
        Assume $R$ is a relation on $\mathbb{Z}$ such as $xRy$ if and only if $x^2 \equiv y^2 \pmod{4}$. We want to prove that $R$ is reflexive, symmetric, and transitive.

        First, we will show that $R$ is reflexive. Take any integer $x \in Z$, and observe that $4 \mid 0$, so $4 \mid x^2 - x^2$. Thus, by definition, $x^2 \equiv x^2 \pmod{4}$. This shows $R$ is reflexive.

        Second, we will show that $R$ is symmetric. Suppose $xRy$ for some $x,y \in \mathbb{Z}$. So $4 \mid (x^2 - y^2)$. This means $(x^2 - y^2) = 4m$ for some $m \in \mathbb{Z}$. Then $y^2 - x^2 = 4(-k)$, so $4 \mid (y^2-x^2)$. Thus by definition, $y^2 \equiv x^2 \pmod{4}$. Therefore $R$ is symmetric.

        Finally, we will show that $R$ is transitive. Suppose $xRy$ and $yRz$ for $x,y,z \in \mathbb{Z}$. So $x^2-y^2 = 4k$ for some integer $k$ and $y^2-z^2 = 4l$ for some integer $l$. Adding these two equations, we obtain $x^2-z^2 = 4(k+l)$, so $4 \mid (x^2-z^2)$. Hence $x^2 \equiv z^2 \pmod{4}$. Therefore $R$ is transitive.

        The past three paragraphs have shown that $R$ is reflexive, symmetric and transitive.
    \end{proof}

\end{problems}

\subsection{Equivalence Relations}

\begin{problems}
    \problem Let $A = \set{a,b,c,d,e}$. Suppose $R$ is an equivalence relation on $A$. Suppose $R$ has two equivalence classes. Also $aRd$, $bRc$ and $eRd$. Write out $R$ as a set.

    \answer Since $aRd$ and $eRd$, the elements $a$, $d$ and $e$ lie in one equivalence class, and since $bRc$, the elements $b$ and $c$ lie in another. These are the two classes: $[a] = [d] = [e] = \set{a,d,e}$ and $[b] = [c] = \set{b,c}$. Each class $X$ contributes the pairs $X \times X$ to $R$, so
    \begin{align*}
        R = \{ & (a,a),(d,d),(e,e),(a,d),(d,a),(a,e),(e,a),(d,e),(e,d),\\
               & (b,b),(c,c),(b,c),(c,b) \}.
    \end{align*}

    \problem Let $A = \set{a,b,c,d,e}$. Suppose $R$ is an equivalence relation on $A$. Suppose also that $aRd$ and $bRc$, $eRa$ and $cRe$. How many equivalence classes does $R$ have?

    \answer $R$ has one equivalence class. Since $aRd$ and $eRa$, the elements $a$, $d$ and $e$ lie in one class, and since $bRc$ and $cRe$, the elements $b$, $c$ and $e$ lie in one class. As $e$ belongs to both, all five elements share a single class: $[a] = [b] = [c] = [d] = [e] = A$.

    \problem There are five different equivalence relations on the set $A = \set{a,b,c}$. Describe them all. Diagrams will suffice.

    \answer $R_1 = \set{(a,a),(b,b),(c,c)}$\\ 
    $R_2 = \set{(a,a),(b,b),(c,c),(a,b),(b,a)}$\\ 
    $R_3 = \set{(a,a),(b,b),(c,c),(a,c),(c,a)}$\\ 
    $R_4 = \set{(a,a),(b,b),(c,c),(b,c),(c,b)}$\\ 
    $R_5 = \set{(a,a),(b,b),(c,c),(a,b),(b,a),(a,c),(c,a),(b,c),(c,b)}$.

    \problem Define a relation $R$ on $\mathbb{Z}$ as $xRy$ if and only if $x^2 + y^2$ is even. Prove $R$ is an equivalence relation. Describe its equivalence classes.
    
    \begin{proof}
        By definition, $xRy$ means $x^2 + y^2$ is even. We want to prove $R$ is an equivalence relation, that is, $R$ is reflexive, symmetric, and transitive.

        First, we will show $R$ is reflexive. 
        Take any $x \in \mathbb{Z}$.
        Then $x^2 + x^2 = 2(x^2)$ is even, so $xRx$. Thus $R$ is reflexive. 

        Second, we will show $R$ is symmetric. Assume $xRy$ for some $x,y \in \mathbb{Z}$. Since $xRy$, we know $x^2+y^2$ is even, so $x^2+y^2 = 2k$ for some integer $k$. From the commutative property of addition $x^2+y^2 = y^2+x^2$. So $y^2+x^2 = 2k$. From this it follows that $y^2+x^2$ is even, so $yRx$.
        Thus $R$ is symmetric.

        Last, we will show $R$ is transitive. Assume that $xRy$ and $yRz$ for some $x,y,z \in \mathbb{Z}$. Since $xRy$ and $yRz$, it follows $x^2+y^2$ is even and $y^2+z^2$ is even, so $x^2+y^2 = 2m$ and $y^2+z^2 = 2n$ for some $m,n \in \mathbb{Z}$. Adding these equations we get,
        \begin{align*}
            (x^2+y^2) + (y^2+z^2) &= 2m + 2n\\ 
            x^2+y^2+y^2+z^2 &= 2m + 2n\\ 
            x^2+2y^2+z^2 &= 2m + 2n\\ 
            x^2+z^2 &= 2m + 2n - 2y^2\\ 
            x^2+z^2 &= 2(m+n-y^2)
        \end{align*}
        So $x^2+z^2$ is even, so $xRz$. Thus $R$ is transitive.
        
        The three paragraphs have shown that $R$ is reflexive, symmetric, and transitive. Therefore $R$ is an equivalence relation.
    \end{proof}

    \problem Suppose $R$ and $S$ are two equivalence relations on a set $A$. Prove that $R \cap S$ is also an equivalence relation. (For an example of this, look at Figure 11.2. Observe that for the equivalence relations $R_2, R_3$ and $R_4$, we have $R_2 \cap R_3 = R_4$.)

    \begin{proof}
        Assume $R$ and $S$ are equivalence relations on set $A$. We want to prove $R \cap S$ is also an equivalence relation.

        First, we show $R \cap S$ is reflexive. Take any element $a$ in $A$.
        Since $R$ is an equivalence, then $aRa$.
        Since $S$ is an equivalence relation, then $aSa$.
        Thus $a$ is related to itself by both $R$ and $S$, Hence $a (R \cap S) a$. Therefore $R \cap S$ is reflexive.

        Second, we show $R \cap S$ is symmetric. Take any $a,b \in A$ such that $a(R \cap S)b$. This means that both $aRb$ and $aSb$.
        Since $R$ is symmetric $bRa$.
        Since $S$ is symmetric $bSa$.
        Thus $b$ is related to $a$ by both $R$ and $S$, hence $b (R \cap S) a$.
        Therefore $R \cap S$ is symmetric.

        Last, we show $R \cap S$ is transitive. Take any $a,b,c \in A$ and suppose $a(R \cap S)b$ and $b(R \cap S)c$.
        By definition of intersection it follows $aRb$, $bRc$ and $aSb$, $bSc$.
        Since $R$ is transitive $aRc$.
        Since $S$ is transitive $aSc$.
        Thus $a$ is related to $c$ by both $R$ and $S$, hence $a(R \cap S)c$.
        Therefore $R \cap S$ is transitive.
        
        We have shown that if $R$ and $S$ are equivalence relations on a set $A$, then the intersection of $R$ and $S$ is also an equivalence relation.
        
    \end{proof}

    \problem Prove or disprove: If $R$ and $S$ are two equivalence relations on a set $A$, then $R \cup S$ is also an equivalence relation on $A$.

    \problem Suppose $R$ is a reflexive and symmetric relation on a finite set $A$. Define a relation $S$ on $A$ by declaring $xSy$ if and only if for some $n \in \mathbb{N}$ there are elements $x_1, x_2, \dots, x_n \in A$ satisfying $xRx_1$, $x_1Rx_2$, $x_2Rx_3$, $x_3Rx_4, \dots, x_{n-1}Rx_n$, and $x_nRy$. Show that $S$ is an equivalence relation and $R \subseteq S$. Prove that $S$ is the unique smallest equivalence relation on $A$ containing $R$.
\end{problems}
