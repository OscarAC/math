:::meta lang: en title: Projects · OzkrAC description: Projects by OzkrAC, starting with Tern. ::: :::use ../lib/site.js ../lib/site.css ::: # Projects ## Tern {#tern} A level above Markdown, a level below LaTeX. A Tern note is one `.html` file that renders itself in the browser: headings, numbered theorems and figures, references, footnotes and TeX math, with no build step. The [wiki](../wiki/) is written in it. [Documentation](/tern/) · [Source](https://github.com/OzkrAC/tern) ## Lightc {#lightc} A freestanding C runtime for Linux. No libc, no system linker scripts, no external dependencies — everything from _start to exit is implemented on raw Linux syscalls. Targets x86_64 and aarch64. [Documentation](/lightc/) · [Source](https://github.com/OzkrAC/lightc)
