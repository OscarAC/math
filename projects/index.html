:::use ../lib/site.js ../lib/site.css ::: # Projects ## Tern {#tern} A level above Markdown, a level below LaTeX. A Tern note is one `.html` file that renders itself in the browser: headings, numbered theorems and figures, references, footnotes and TeX math, with no build step. The [wiki](../wiki/) is written in it. [Documentation](/tern/) · [Source](https://github.com/OzkrAC/tern)
